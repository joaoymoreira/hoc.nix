* Description

Nix packages for Higher Order Company's software as a nix flake.

* Installation and usage

Available packages are bend/bend2 and kind2.

** nix shell

#+begin_src
nix shell github:joaoymoreira/hoc.nix#bend
bend --help
#+end_src

#+begin_src
nix shell github:joaoymoreira/hoc.nix#kind2
#+end_src

** NixOS

1. Set a flake input for hoc.nix on your =flake.nix=:
   #+begin_src
{
  inputs = {
    hoc.nix = {
      type = "github";
      owner = "joaymoreira";
      repo = "hoc.nix";
    };
  };
}
   #+end_src

2. Pass it to outputs:
   #+begin_src
outputs = (inputs@{
  self
  , nixpkgs
  , hoc.nix
  , ...
}:
   #+end_src

3. Add packages to the packages set
   #+begin_src
{
  environment.systemPackages = (with pkgs; [
    inputs.nix-init.packages."x86_64-linux".bend
    inputs.nix-init.packages."x86_64-linux".kind2
  ]);
}
   #+end_src

4. nixos-rebuild
   #+begin_src
sudo nixos-rebuild switch --print-build-logs --flake '/path/to/nixos#configuration'
   #+end_src

5. Open new shell and use the binary
   #+begin_src
bend --help
   #+end_src
